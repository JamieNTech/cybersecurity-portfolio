# Screenshots & Visuals

Supporting images referenced from project write-ups. Prefer to keep screenshots inside their own project folder when possible — use this folder only for images that are shared across multiple projects, or that don't yet belong to one.

## Naming

Use lowercase, hyphenated names so the images are easy to reference from Markdown:

```
2024-06-19-wireshark-tls-handshake.png
2024-08-05-risk-register-overview.png
```
